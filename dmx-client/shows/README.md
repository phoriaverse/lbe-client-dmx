# shows/

Baked `.show` files live here. They are build output from `lighting-editor` (or from
`bun run make-test-show`) and are gitignored — megabytes each, and regenerated by a bake.

A show Mac needs these files and nothing else from the editor. Each one carries its own patch and
the name of the experience it answers to; the client reads the headers and matches the name the
control server sends. To move a show to another machine, copy the file.

A show whose experience name is `ambient` plays as the idle loop between sessions.
